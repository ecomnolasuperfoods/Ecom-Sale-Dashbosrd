# Nola Superfoods — Data Dashboard 2026

แดชบอร์ดสถิตแบบไฟล์เดียว (static site) สรุปผลประกอบการปี 2026 ของ Nola Superfoods
สร้างจากไฟล์ Excel ต้นทาง `Nola Superfood Sale 2026 14.xlsx`

**หน้าเว็บ:** https://ecomnolasuperfoods.github.io/Ecom-Sale-Dashbosrd/
(ตั้งค่าไว้ที่ Settings → Pages → Source: Deploy from a branch → `main` / `(root)` — push ขึ้น main แล้ว deploy เองอัตโนมัติ)

## แดชบอร์ดมีอะไรบ้าง

| แท็บ | เนื้อหา |
|---|---|
| **ภาพรวม** | KPI สะสมปี 2026, GMV รายเดือนเทียบเป้าและปี 2025, สัดส่วนรายแพลตฟอร์ม, แนวโน้มรายปี, ตารางสรุปรายเดือน, ประเด็นที่ต้องตาม |

## โครงสร้างไฟล์

```
index.html                     หน้าเว็บหลัก
assets/styles.css              ธีม (รองรับโหมดสว่าง/มืด)
assets/app.js                  โค้ดสร้างกราฟและตารางทั้งหมด
assets/chart.umd.js            Chart.js 4.4.7 (vendor ไว้ในโปรเจกต์ ไม่ต้องต่อ CDN)
data/data.json                 ข้อมูลที่สกัดจากไฟล์ Excel
scripts/extract.py             สคริปต์แปลง .xlsx → data.json
scripts/build_standalone.py    รวมทุกอย่างเป็นไฟล์เดียวใน dist/
dist/nola-dashboard.html       เวอร์ชันไฟล์เดียว ดับเบิลคลิกเปิดได้เลย ส่งต่อทางแชตได้
```

## อัปเดตข้อมูลรอบใหม่

1. วางไฟล์ Excel เวอร์ชันใหม่ไว้ที่ `nola.xlsx` (หรือแก้ path ในสคริปต์)
2. รัน

```bash
pip install openpyxl
python3 scripts/extract.py
```

3. ตรวจหน้าเว็บในเครื่อง — ต้องเปิดผ่าน HTTP server เพราะหน้าเว็บ `fetch` ไฟล์ JSON

```bash
python3 -m http.server 8000
# เปิด http://localhost:8000
```

4. สร้างไฟล์เวอร์ชันเดียวสำหรับส่งต่อ (ไม่ต้องมี server)

```bash
python3 scripts/build_standalone.py
```

5. commit และ push ขึ้น branch `main` — GitHub Pages จะอัปเดตให้เองภายใน 1–2 นาที

## ข้อควรรู้เกี่ยวกับข้อมูล

- **เดือนล่าสุดยังไม่จบเดือน** แดชบอร์ดจะแสดงจำนวนวันที่มีข้อมูลไว้ที่หัวหน้าเว็บ และคำนวณการเทียบแบบ "ต่อวัน" ให้ในกล่องประเด็นที่ต้องตาม เพราะการเทียบยอดรวมทั้งเดือนจะทำให้ดูตกแรงเกินจริง
- **GMV รวมปี 2026** จากตารางรายเดือน = 21,950,610 บาท ส่วนชีต `Sale Yealy` ระบุ 21,936,314 บาท — ต่างกัน 14,296 บาท ซึ่งเท่ากับยอด Line Shopping พอดี (ชีตรายปีไม่ได้รวมช่องทางนี้)
- **ยอด GMV จากโฆษณา** เป็นยอดแบบ attribution จึงซ้อนทับกันได้ และอาจสูงกว่ายอดขายรวมของแพลตฟอร์ม ไม่ควรนำมาบวกกันตรง ๆ
- **แหล่งที่มายอดขาย Shopee** (หน้าสินค้า / Live / วิดีโอ / พาร์ทเนอร์) ก็เป็น attribution เช่นกัน กราฟจึงแสดงเป็นแท่งคู่ ไม่ใช่แท่งซ้อน
- **ข้อมูลสินค้าและสต็อก** มาจากชีต `Mapping all stock` ครอบคลุมยอดขายรายชิ้น ก.ย. 2025 – ก.ค. 2026 (ยังไม่มี ส.ค. ระดับ SKU)
- **จำนวนครีเอเตอร์ TikTok** นับเฉพาะรายที่มี GMV มากกว่าศูนย์ (ไฟล์ต้นทางบางเดือน export รายชื่อครีเอเตอร์ทั้งหมดมาด้วย)

## เทคนิค

- ไม่มี build step ไม่มี dependency ตอน runtime นอกจาก Chart.js ที่ vendor ไว้แล้ว
- ฟอนต์ Noto Sans Thai โหลดจาก Google Fonts และมี fallback เป็นฟอนต์ระบบ
- โหมดสว่าง/มืดตามค่าระบบ และกดสลับเองได้ (จำค่าไว้ใน localStorage)
- จานสีผ่านการตรวจ contrast และการมองเห็นสีบกพร่อง (CVD) ตามมาตรฐานที่ใช้ในโปรเจกต์
